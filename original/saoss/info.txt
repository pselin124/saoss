Minimun system requirements
---------------------------
-8 Mb 3d-graphics card with OpenGl support.
-if your graphics card less than 16 Mb of memory or doesn't have support for  large textures (voodoo3 etc), set 256*256 texture limit by changing mode256=0; -> mode256=1; in sets.txt 
-A sound card for game sounds.

Recommended system specs
------------------------
-32 Mt fast graphics card, only required for high resolutions and details.
-500 Mhz CPU for 2-6 player games (Tested with p3 500 Mhz Tnt 16 MB) 
-0.7-2 Ghz for 8-16 player games

-Joining games
   -128 kbit/sec network bandwith (download)
   -16 kbit/sec (upload)
   -low latency times (Tested and created in LAN)
-Hosting games
   -16 kbit/sec * number_of_clients (download)
   -128 kbit/sec * number_of_clients (upload)
   -low latency times

Saoss was mainly tested with 2.8 Ghz p4, radeon 8500, 1024 MB ddr 
 & 2.1 Ghz Athlon XP, gf2ti, 768 sdr. Saoss uses tcp-port 9999 for all network traffic
 clients should work fine behind NAT.

Installing and Running Saoss
----------------------------

There is 3 different packages available. Win32, Linux compiled version (i586) and full version with source codes.
These packets can be downloaded from http://www.hut.fi/~pselin/saoss/

Win32 version: saosswin32.exe and run saoss from Start-menu.

linux: 
 after unpacking
  -i586: Install SDL, SDL_Image, SDL_Net and fmod _or_ 
          a) open your /etc/ld.so.conf -file
          b) pick one of directories listed there
          c) copy saoss/lib/*.* to that directory
	  d) run ldconfig
          e) run ./saoss
  -other: a) Install SDL, SDL_Image, SDL_net and fmod. If you fail to do install these, 
              try i586 version installation for libraries.
	  b) Compile saoss by typing make in the saoss directory. 
          c) type ./saoss in the saoss directory


TroubleShooting
---------------
If the game does not start, try editing sets.txt.

If some textures don't work or the main menu is weird edit sets.txt 
 "mode256=0;" -> "mode256=1;"
