Minimun system requirements
---------------------------
-8 Mb 3d-graphics card with OpenGl support.
-if your graphics card less than 16 Mb of memory or doesn't have support for  large textures (voodoo3 etc), set 256*256 texture
 limit by changing mode256=0; -> mode256=1; in sets.txt 

Recommended system specs
------------------------
-32 Mt fast graphics card, only required for high resolutions and detail level.
-300-500 Mhz CPU for 2-6 player games (not tested under 1200 Mhz :) 
-1000-2000 Mhz for 8-16 player games
-128 kbit/sec network bandwith with low pings for joining games
-128 kbit/sec * number_of_clients for hosting games

Running Saoss
-------------
Windows: just start saoss.exe
linux: 
 -386  : just run "saoss" in saoss-directory
 -other: Install SDL, SDL_Image, SDL_net and fmod, compile and run saoss.
